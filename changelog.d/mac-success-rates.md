- **Shared core (Mac and iPhone): a printer's success rate can be worked out natively, by the desktop's own rule.** `lib/printer-success.js` is now in KhaytCore's bundle. `KhaytEngine.successRates(orders:machines:from:to:calendar:)` returns each printer's finished, failed, cancelled and unknown runs, its rate, and whether there are enough decided runs to show one (`successRunsNeeded()`, five); with a calendar, each run counts on that calendar's own day (the book's, through daylight-saving changes too), not the UTC day. `KhaytEngine.successPercent(_:)` gives the whole per cent every app shows, where 199 of 200 reads 99 and never 100. Nothing on screen changes here: the iPhone's "Success rate" line and the Mac's Machine profit read it. Held to the vectors the Windows/Linux app's own test runs.
