- **Mac: when a slicer crashes, Khayt says so in plain words.** Sending a model to a printer used to report "Slicing failed: The slicer produced no G-code. signal 11", which read as if Khayt had failed. It now says the slicer crashed, and suggests another slicer or slicing the file in the slicer itself. (The Snapmaker Orca crash that showed this every time is fixed separately: it was the way Khayt started the slicer.)
- **Mac: Settings › Internet use says what the switch cannot stop.** A slicer that Khayt runs, such as Snapmaker Orca, is its own program and can still go online by itself to send its crash reports to its maker; the page now says so, so "Make no internet calls" never promises more than it does.
