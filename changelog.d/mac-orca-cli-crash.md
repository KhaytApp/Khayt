- **Mac: sending an STL to a Snapmaker U1 with Snapmaker Orca no longer fails with "Slicing failed: … signal 11".** Khayt handed Snapmaker Orca your printer, print and filament settings as separate files, and its command-line slicer crashes on that every time. Khayt now puts the same settings inside a project file and slices that, the way Snapmaker Orca slices a project you save yourself. A 3MF that already carries its own settings is sliced as it is. A model that is not an STL or a 3MF (an OBJ, for example) is not sliced from Khayt with these slicers; open it in the slicer itself. The same change applies to quotes worked out from an uploaded model.
