- **Fixed (Windows/Linux): "Slice for exact quote" on an STL, or a 3MF with no settings of its own, no longer crashes Snapmaker Orca.** Khayt handed such a model to an Orca slicer with its printer, print and filament settings as command-line options, and Snapmaker Orca 2.4.1 crashes on those every time, so no quote came back. Khayt now makes the model a project that carries those settings inside it (an STL is placed on the printer's bed; a 3MF keeps every part of the file as it was and gains the settings) and slices that, as the Mac does. An STL over 150 MB is not sliced from Khayt: open it in the slicer itself. A large STL is built in about a second without holding the whole mesh in memory twice.
