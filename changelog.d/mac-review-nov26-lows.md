- **Mac: a Keep tick on the Mac no longer drops a purpose only a newer Khayt knows.** With "Make no internet calls" on, ticking or unticking Keep on one row kept only the purposes this Mac knew, so a purpose a newer Windows/Linux app had ticked was silently removed from the book. It now stays, as it already did when a phone changed the list. `lan` and the switch-sync call are still never in the list.
- **(Maintainers) Mac release: the publish step checks the commit that was built, and the build refuses any bundled file that differs from `lib/`.** `mac/release-local.sh` now sends the build's commit to `mac-publish.yml`, which checks it out (after confirming it is on main) instead of main's tip, so the version check, the notes and the feed are the build's even when main has moved on. Before building, the release worktree now refuses to go on when `mac/sync-js.sh` changes any bundled module, locale or resource copy, not just `release-gates.json`. From the Nov 26 release review (L1, L2).
