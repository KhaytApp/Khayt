- **(Maintainers) A Mac release can stop at the draft.** `mac/release-local.sh --draft-only` builds, notarises, checks and uploads the draft release, and stops: nothing is signed, made public or offered to any install, so the build can be installed by hand and tried first. `mac/release-local.sh --publish` is the second step: it builds nothing, needs the draft to exist, and does what the plain run always did after the upload (sign the archive and the feed, check both, make the release public, publish the feed). Run with neither, it does both, as before. A test runs the real script with stand-in tools and shows that `--draft-only` never starts the publish.
