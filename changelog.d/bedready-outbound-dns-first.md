- **Bed Ready: with "Make no internet calls" on, downloading a MakerRun design or its cover no longer looks up the design's host first.** The download guard checked the address (a DNS query, which is itself a call out) before it asked the switch, so the request was refused but the host's name had already left the computer. It now asks first. A new test runs every call Bed Ready makes (MakerRun library, catalogue, publishing and sign-in refresh, and the filament library) against the real gate with the switch on, and checks that none of them sends a request or a DNS lookup, and that a refused refresh keeps the MakerRun link.
