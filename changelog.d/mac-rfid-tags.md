- **Spool tags: a spool is recognised by its tag's id, and more kinds of tag are read.** A U1 reads a tag on each side of a reel, and the two tags have different ids, so a spool now keeps every tag id it has been seen with. A head whose tag id belongs to one of your spools is that spool, even when the tag carries nothing else Khayt can read. A tag id Khayt has not seen before proves nothing, and the spool is still matched by material, colour and maker. A tag that names its maker as "Generic" no longer stops a match with a branded spool, and a colour sent as text is read. A spool added from a tag remembers that tag. Khayt never writes to a printer's tag data.
