- **Fixed (Windows/Linux): a computer that ran 4.11 is not asked about 4.11.0's "Before you update" items again.** Builds before 4.12.0 did not record which version had been read, so the first start of 4.12.0 asked every shop about 4.11.0's two items once more. Khayt now counts from the version that last opened the book (which every build since 3.11.6 notes), and asks only about what is new since; a computer with no note at all is still asked, the safe way.
- **Fixed (Windows/Linux, security): "Before you update" items accepted in the update dialog count only in the words that were shown.** The dialog's translations come with the release, which the app cannot check; accepting used to mark the whole version read, so a replaced text could stand in for the real one. Now the first start after the update skips only the items whose own text was shown, and asks again about any other.
- **Changed (Windows/Linux): with "Make no internet calls" on, a service named like a local one is no longer looked up by name.** A name such as `mail.lan`, `nas.internal` or a single word could be passed to an outside name server while the switch was on. Such a service is now treated as the purpose it serves: kept, it works; otherwise it waits like the rest. A `.local` name, a numeric address and the shop's printers are unchanged.
