        Print library location

        Where your model files are kept. A folder on a network drive, an external disk, or a synced folder (iCloud Drive, Dropbox, Google Drive, OneDrive) all work — Khayt just needs to be able to reach it.

        Every file added to the library is copied here too. Khayt never reads from it — it is a backup, not a second library.

        Files left in the old location

        Each file is copied, read back and checked before the original is removed. Nothing is overwritten, and anything that cannot be verified is left where it is.

        A second copy of every file, off-site. On its own this is only a backup — it does not free up any space here. To do that, switch on cloud storage below.

        Khayt can only see the files it puts there itself — it has no access to the rest of your Drive. You will need a free OAuth client ID from a Google Cloud project; the setup guide is in the docs.

        Models you have not touched in a while are uploaded, checked, and then removed from this computer. They stay in your library and download again automatically the moment you open one. Thumbnails always stay local, so browsing still works offline.
