# Khayt Companion — design v2 (the current one)

**This is the source of truth for the iOS app's UI.** It is an export of Turki's
Claude Design project *Khayt Mobile App Design*
(claude.ai/design/p/4270b077-e890-472b-a30d-c69a95da679c):

- `Khayt Companion Prototype v2.dc.html` — the working prototype: 16 screens,
  both languages, both themes, with the designer's decisions beside each.
- `Khayt Copy Reconciliation.dc.html` — every string, EN and AR, mapped and
  classed, with the Arabic findings.

The older mockup in `design/iOS UI/` is **superseded** — the app was built
against it for a while by mistake, which is why this folder exists in the repo.

To refresh: Claude Design → Share → Export → Project HTML → Project archive,
then replace these files. Open the `.dc.html` files in a browser to see them.
