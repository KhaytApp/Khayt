# Quando algo está errado

## "Aberto somente para leitura"

O Khayt para Windows e Linux está com o livro aberto, ou outro Mac está. Um app
escreve um livro de cada vez, de propósito: dois escrevendo ao mesmo tempo é
como o trabalho de uma tarde desaparece. Feche-o lá e use **Livro → Recarregar
do disco**.

## Um valor aqui discorda do outro app

Não deveria — os dois calculam a partir das mesmas regras compartilhadas. Duas
coisas fazem parecer que discordam:

- **Os livros são diferentes.** Confira o nome no canto superior esquerdo; um
  livro de desenvolvimento e um distribuído são dois arquivos diferentes.
- **Um deles está desatualizado.** **Livro → Recarregar do disco** depois que o
  outro app gravou.

Se ainda discordar, vale relatar, com os dois valores.

## A impressora não diz nada

- Confira o endereço e a chave com **Testar** na máquina.
- Uma impressora que mudou para um novo endereço costuma ser seguida
  automaticamente, mas só depois que o Khayt viu o número de série dela — uma
  impressora que ele nunca alcançou não pode ser reconhecida depois.
- As impressoras Bambu informam só o status. O controle remoto exige o conector
  próprio da Bambu.

## Um modelo não importa

- Ele pode já estar lá. O Khayt reconhece um arquivo pelo conteúdo, não pelo
  nome, e recusa uma duplicata.
- Só arquivos de modelo e de G-code são aceitos; tudo o mais em uma pasta é
  ignorado.
- Importar a pasta da sua própria biblioteca para dentro dela mesma não faz
  nada, de propósito.

## Conseguir uma versão que funcione

**Khayt → Buscar atualizações…**. Se o app não abre de jeito nenhum, nenhuma
atualização consegue chegar até você — o Sparkle roda dentro do app — e a versão
precisa ser baixada manualmente na página de lançamentos.
