# Backups

O Khayt faz uma cópia do seu livro antes de qualquer coisa que o reescreva e
guarda as mais recentes.

## Fazer um agora

**Livro → Fazer backup agora**. **Livro → Mostrar backups** abre a pasta no
Finder, que é para onde você vai se quiser copiar um deles para outro lugar.

## Restaurar

**Livro → Restaurar** lista o que existe, do mais novo para o mais antigo.
Restaurar substitui o seu livro atual por aquela cópia — por isso o Khayt faz
primeiro um backup do livro atual, o que significa que mudar de ideia também é
possível.

## O que não é um backup

**Exportar uma cópia** não é um backup e tem esse nome para que ninguém recorra
a ele como se fosse. É a cópia que sai daqui — ela teve as suas credenciais
removidas e serve para ser enviada a algum lugar, não para restaurar.

## Onde ficam

Na pasta do próprio app, ao lado do livro. Ficam somente neste Mac: se o disco
se for, eles vão junto. Ainda vale ter uma cópia em outro lugar.
