# Welches Buch geöffnet ist

Alles auf dem Bildschirm stammt aus einer einzigen Datei – dem Buch Ihres
Betriebs. Die Symbolleiste nennt jederzeit oben links, welches, und es ist das
Einzige in dieser App, bei dem Sie nie raten müssen sollten.

## Die drei, die Sie sehen können

- **Beispiel-Shop** – erfundene Daten, damit die App etwas zu zeigen hat, bevor
  Sie ein Buch haben. Sie können unbesorgt alles anklicken. Es ist nie die Lage
  Ihres Betriebs, und es sagt das auch.
- **Khayt** – das Buch, das das ausgelieferte Khayt für Windows und Linux führt.
- **khayt** (klein geschrieben) – das Buch, das ein Entwicklungs-Build führt. Wenn
  Sie immer nur ein veröffentlichtes Khayt benutzt haben, sehen Sie dieses nicht.

Das Menü listet die echten Bücher **zuletzt beschriebene zuerst**, sodass das
Buch, das Sie tatsächlich führen, oben steht. Die App öffnet Ihr eigenes Buch,
wenn es eines gibt, und das Beispiel nur, wenn nicht.

## Eine App zur Zeit

Ein Buch wird jeweils von einer App geschrieben. Hat Khayt für Windows und Linux
es geöffnet, öffnet diese App es **schreibgeschützt**: Sie können alles ansehen
und nichts ändern, und die Bildschirme sagen, wer es gerade hält.

Das ist keine Vorsicht um ihrer selbst willen. Zwei Apps, die dieselbe Datei
schreiben, sind der Weg, auf dem ein Betrieb die Arbeit eines Nachmittags
verliert, und die Sperre macht es unmöglich statt nur unwahrscheinlich.

## Neu laden

Die Mac-App liest das Buch beim Öffnen und nach allem, was sie schreibt. Hat die
andere App etwas geändert, während diese offen war, holt **Buch → Von Festplatte
neu laden** es ab.
