# Das Board

Das Board zeigt dieselben Aufträge wie die Tabelle, nach Phase angeordnet – für
die Werkstatt statt für den Schreibtisch. Es ist die Ansicht, die am ehesten den
ganzen Tag offen bleibt.

## Arbeit verschieben

Ziehen Sie einen Auftrag von einer Spalte in die nächste. Das ist dieselbe
Änderung wie über das Menü Auftrag und wird genauso festgehalten – wer einen
Auftrag nach *Abgeschlossen* verschiebt, wird gefragt, was der Druck tatsächlich
gebraucht hat, genau wie im Menü.

## Was angezeigt wird

Jede Karte zeigt den Auftrag, den Kunden, die Maschine, auf der er läuft, und
wann er fällig ist. Dringende Arbeit steht zuerst, dann nach Fälligkeit, dann
nach der längsten Wartezeit – in der Reihenfolge, in der man sie abarbeiten
würde.

Läuft ein Auftrag über seine Schätzung hinaus, erscheint der Timer in einer
anderen Farbe, damit Sie den sehen, der Aufmerksamkeit braucht.

## Das Board folgt der Suche

Das Suchfeld schränkt neben der Tabelle auch das Board ein. Ein voller Betrieb
mit einem eingetippten Kundennamen ist der schnellste Weg, um „Wo ist sein
Auftrag?“ zu beantworten.
