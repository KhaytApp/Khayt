# 云端同步

Khayt Cloud 在多台机器之间传递你的账本，并为客户提供一个可以跟踪订单的页面。它是可选的：没有它，应用也能完整运行。

## 这个应用能做什么

- **检查** — 把你的账本与云端对比，说明有哪些不同，但不发送任何内容。它是只读的，所以在拿不准时运行是安全的。
- **发送** — 把你的账本上传。
- **下载仅存在于云端的内容** — 把云端的副本下载下来并合并。

## 你的机密不会离开

账本中保存着云端令牌、打印机的 API 密钥以及存储凭据。在发送任何内容之前，这些都会被取出并替换为掩码。离开的副本绝不包含它们。

## 锁定

**账本 → 锁定 Khayt Cloud**会结束自动同步，并清除内存中保存的密钥。它是唯一的退出方式——如果你要把 Mac 留在不受你控制的地方，值得了解这一点。

## 两台机器

如果两台机器都在使用这个账本，在依赖同步之前，请先把两台都更新。旧版本可能带有新版本已经改动过的字段，而且谁最后写入谁说了算，所以一台停留在旧版本的机器，可能会悄悄地把旧值写回去。
