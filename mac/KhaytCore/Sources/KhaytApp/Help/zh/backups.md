# 备份

在任何会改写账本的操作之前，Khayt 都会先为账本做一份副本，并保留最近的几份。

## 立即备份

**账本 → 立即备份**。**账本 → 显示备份**会在访达中打开备份所在的文件夹，想把备份复制到别处时就从这里去。

## 恢复

**账本 → 从备份恢复…**会按从新到旧的顺序列出现有的备份。恢复会用所选副本替换你当前的账本；不过 Khayt 会先为当前账本做一份备份，所以改变主意也是可以的。

## 什么不是备份

**导出副本…**不是备份，名字也特意区分开，免得有人把它当备份用。它是要带出去的副本，其中的凭据已被移除，用途是发送给别处，而不是用来恢复。

## 备份在哪里

在应用自己的文件夹里，与账本放在一起。它们只存在于这台 Mac 上：磁盘坏了，备份也就没了。在别处另存一份仍然值得。
