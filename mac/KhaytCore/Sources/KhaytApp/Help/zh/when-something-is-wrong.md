# 出问题时

## “以只读方式打开”

Windows 和 Linux 版 Khayt 正打开着账本，或是另一台 Mac 在打开。账本一次由一个应用写入，这是有意为之：两个同时写入，一个下午的工作就会消失。在那边关闭它，然后使用**账本 → 从磁盘重新载入**。

## 这里的数字与另一个应用不一致

不应该不一致——两者都按同一套共用规则计算。有两种情况会让它们看起来不一致：

- **账本不同。**查看左上角的名称；开发版账本和正式版账本是两个不同的文件。
- **其中一个已过时。**另一个应用写入之后，请使用**账本 → 从磁盘重新载入**。

如果仍然不一致，值得报告，请附上两个数字。

## 打印机没有任何反应

- 用机器上的**测试**检查地址和密钥。
- 换了新地址的打印机通常会被自动找到，但前提是 Khayt 已经见过它的序列号——从未连接成功过的打印机，之后无法被识别。
- Bambu 打印机仅显示状态。远程控制需要 Bambu 自己的连接器。

## 模型无法导入

- 它可能已经在库中了。Khayt 通过内容而不是名称来识别文件，并拒绝重复项。
- 只会接收模型文件和 G-code 文件；文件夹中的其他内容都会被跳过。
- 把你自己的模型库文件夹导入它自己，什么也不会发生，这是有意设计的。

## 获取一个能用的版本

**Khayt → 检查更新…**。如果应用根本无法启动，任何更新都无法送达——Sparkle 运行在应用内部——那就必须从发布页面手动下载版本。
