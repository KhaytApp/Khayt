# 设置

按 ⌘, 打开。它们的写入规则与 Windows 和 Linux 版 Khayt 的保存规则相同，所以在这里改的设置，在那边的含义也一样。

## 值得先设置的内容

- **店铺信息** — 名称、地址、联系方式、营业执照编号和增值税号。这些会出现在每张发票上。
- **货币** — 应用中所有数字使用的货币。
- **税** — 是否收取增值税、税率是多少，以及是否适用 ZATCA 的要求。
- **语言** — Khayt 自身的界面语言。选阿拉伯语会让整个应用从右到左排版。
- **产品语言** — 你的产品使用哪些语言书写。产品编辑器中的标签页由此决定。
- **利润率** — 产品没有设置自己的利润率时，价格按此计算。
- **工作日** — 店铺哪几天营业，所有交付周期和产能数字都以此为基准来计算。

## 界面语言属于店铺，而不是这台 Mac

Khayt 遵循你在这里设置的语言，而不是 Mac 的系统设置。一家在利雅得、使用英文 Mac 的店铺，仍用阿拉伯语记账，这条规则正是为这种情况而设。

更改它会重新启动应用，因为书写方向必须在创建窗口之前确定。

## 机密

打印机密钥、云端令牌和存储凭据保存在 Mac 的钥匙串中，而不在账本里。应用第一次读取其中一项时，macOS 会询问——那个提示来自系统，选择不允许只会让这些字段保持封存，其他一切仍会正常打开。
