# 模型库

你打印的每个模型，连同它的图片、材料构成以及运行成本。

## 导入模型

有三种方式，底层都一样：

- 模型库上的**导入模型**按钮。
- 把文件或整个文件夹拖到模型库上。
- **账本 → 添加模型**，或 ⇧⌘I。

文件夹会被逐层遍历，所以你可以把 Khayt 指向一个下载好的文件夹，让它自己找出里面的模型。不是模型的内容会被悄悄跳过。

## 文件夹变成分组

**模型所在的文件夹会成为它归入的分组。**一个包含七个文件夹、七个模型的下载包，会以七个分组的形式导入，而不是一堆平铺的文件。

用于打包的文件夹会被穿透。位于

`Saudi Kings/King Abdulaziz/STL/presupported/crown.stl`

的模型会归入 **King Abdulaziz**，而不是 *presupported*、*STL* 或 *files*，因为这些描述的是文件，而不是在给事物命名。

单独选取的文件不会被分组。一个文件算不上一套。

## 重复项

已有的模型是通过文件内容而不是名称来识别的，重复的会被拒绝，而不是添加两次。重命名文件骗不过它；从切片软件重新导出同一个模型，通常会改变字节，那时它才真的是一个新文件。

## 查看模型

模型库是网格形式，因为打印店是凭外观认出模型的。按空格键会打开快速查看，与访达中一样。方向键可以在网格中移动，在阿拉伯语窗口中，它们的方向也是正确的。
