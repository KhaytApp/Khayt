# 打开的是哪个账本

屏幕上的一切都来自同一个文件——你店铺的账本。工具栏左上角始终注明是哪一个，这是这个应用里你唯一不该去猜的东西。

## 你可能看到的三种

- **示例店铺** — 虚构的数据，让应用在你有账本之前也有东西可展示。放心点按任何地方。它绝不代表你店铺的实际状况，并且会明确说明这一点。
- **Khayt** — 已发布的 Windows 和 Linux 版 Khayt 所使用的账本。
- **khayt**（小写）— 开发版本所使用的账本。如果你只用过正式发布的 Khayt，就不会看到这一个。

菜单按**最近写入的在前**列出真实的账本，所以你实际在使用的账本排在最上面。有你自己的账本时，应用会打开它，没有时才打开示例。

## 一次只有一个应用

账本一次只由一个应用写入。当 Windows 和 Linux 版 Khayt 打开着它时，本应用会以**只读**方式打开：你可以查看一切，但不能更改任何内容，界面上会说明是谁在占用。

这并非为谨慎而谨慎。两个应用写同一个文件，会让店铺丢掉一个下午的工作，而这把锁让这种事不是“不大可能”，而是“不可能”。

## 重新载入

Mac 应用在打开时以及它写入任何内容之后读取账本。如果在本应用打开期间，另一个应用更改了某些内容，**账本 → 从磁盘重新载入**会把它读进来。
