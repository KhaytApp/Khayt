# 欢迎使用 Khayt for Mac

Khayt 为 3D 打印店管理账本：你接过的订单、它们让你花了多少、你收了多少、货架上有什么，以及打印机在做什么。

这是 Mac 版应用。它读写的账本与 Windows 和 Linux 版 Khayt 相同，每个数字都用同一套共用规则计算——所以这里的合计与那里的合计是同一个数字，而不是两种看法。

## 从哪里开始

如果你从未打开过 Khayt，应用会打开一个**示例店铺**：一个虚构的账本，里面有订单、机器和模型，让每个界面都有东西可看。你对它做的任何操作都不会影响真实的账本，工具栏中也始终标明它的名称。

有了真实的账本之后，从左上角的同一个菜单中选择它。这些名称的含义，请参阅**打开的是哪个账本**。

## 这个应用用来做什么

- 接订单，让它在店里流转，并开具账单。
- 了解一次打印实际花了多少——耗材、机器时间、电费、失败的损耗。
- 保管你打印的模型和你销售的产品。
- 不必站在打印机前，也能看着它们。

## 目前仍只在另一个应用里的功能

Mac 应用较新，有些功能目前仍只能在 Windows 和 Linux 版 Khayt 中使用。其中包括：部分不常用的分析视图（资金本身以及大多数店铺常用的报表都在这里的“报表”中）、日终 PDF、按客户自己的货币开具发票、班次检查清单、HueForge 标签页，以及将订单直接发送到 Bambu 打印机。两边的账本是同一个文件，所以你可以在那边做一部分，其余在这边完成。
