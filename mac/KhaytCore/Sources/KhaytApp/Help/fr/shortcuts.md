# Clavier

## Se déplacer

- **⌘K** — aller à n’importe quoi : saisissez le numéro d’une commande ou d’une
  facture, le nom ou le téléphone d’un client, un modèle, un produit, une machine
  ou un écran, puis **↑**/**↓** pour choisir, **↩** pour l’ouvrir et **Échap** pour
  fermer. Les chiffres arabes fonctionnent aussi.
- **⌘J** — sauter dans la bibliothèque : un modèle, un dossier, un fichier
  compressé, une étiquette ou une recherche enregistrée, la meilleure
  correspondance d’abord et celles que vous avez utilisées récemment avant les
  autres. **↩** l’ouvre, **⌘↩** démarre un devis à partir d’un modèle et **⌥↩** une
  nouvelle commande.
- **⌥⌘1** à **⌥⌘4** — le modèle sélectionné dans le volet de détails vu en
  trois quarts, de face, de dessus ou de côté (Présentation ▸ Vue du modèle).
- **⌘F** — le champ de recherche.
- **⌘R** — recharger le livre depuis le disque.
- **⌘,** — réglages.
- **⌘?** — cette aide.

## Travail

- **⌘N** — nouvelle commande.
- **⇧⌘I** — ajouter des modèles à la bibliothèque.
- **Espace** — Aperçu rapide du modèle sélectionné, comme dans le Finder.
- **⌘Z** — annuler la dernière modification du livre.
- **⌘P** — imprimer ce qui est au premier plan : la facture (ou le devis) de la
  commande sélectionnée, ou le compte de résultat dans Rapports. **⌥⌘P** affiche
  la facture à la place.
- **⌘D** — dupliquer la commande sélectionnée (elle s’ouvre dans Nouvelle commande,
  avec le même client, les mêmes pièces et notes) ou le produit du catalogue
  sélectionné.
- **⌫** ou **⌘⌫** — supprimer les modèles sélectionnés dans la bibliothèque, après
  confirmation. Seuls les modèles que vous voyez partent — jamais ceux repliés dans
  un groupe. Dans la liste des commandes, le tableau ou la liste des clients, cela
  supprime à la place les commandes ou clients choisis. Une commande avec un numéro
  de facture ou un paiement n’est jamais supprimée — annulez-la plutôt — et un
  client qui a une commande ou une carte cadeau reste.
- **⇧⌘D** — marquer le modèle sélectionné comme favori.
- **Fichier → Partager…** — envoyer la facture de la commande sélectionnée, ou les
  fichiers des modèles sélectionnés, via le menu de partage du Mac.

Déposez un fichier .3mf, .stl, .obj ou .gcode sur la liste des commandes ou sur
l’icône de Khayt dans le Dock pour démarrer une nouvelle commande à partir de
celui-ci. Il est d’abord ajouté à la bibliothèque.

## Dans la bibliothèque

Les flèches parcourent la grille, et **⇧** avec elles étend la sélection. Dans une
fenêtre arabe, elles vont de droite à gauche, de sorte que « suivant » reste le
suivant.

## Dans les tables

Cliquez sur un en-tête de colonne pour trier selon elle. Les colonnes elles-mêmes
peuvent être affichées, masquées et réordonnées — clic droit sur la ligne
d’en-têtes.
