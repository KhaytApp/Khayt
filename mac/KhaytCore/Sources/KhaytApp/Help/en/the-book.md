# Which book is open

Everything on screen comes from one file — your shop's book. The toolbar names
which one at all times, in the top-left, and it is the one thing in this app you
should never have to guess about.

## The three you may see

- **Sample shop** — invented data, so the app has something to show before you
  have a book. Safe to click anything in. It is never your shop's position, and
  it says so.
- **Khayt** — the book the shipped Khayt for Windows and Linux keeps.
- **khayt** (lower case) — the book a development build keeps. If you have only
  ever used a released Khayt, you will not see this one.

The menu lists the real books **most recently written first**, so the book you
are actually keeping is at the top. The app opens on your own book when there is
one, and on the sample only when there is not.

## One app at a time

A book is written by one app at a time. When Khayt for Windows and Linux has it
open, this app opens it **read-only**: you can look at everything and change
nothing, and the screens say who is holding it.

That is not caution for its own sake. Two apps writing the same file is how a
shop loses an afternoon's work, and the lock is what makes it impossible rather
than unlikely.

## Reloading

The Mac app reads the book when it opens and after anything it writes. If the
other app has changed something while this one was open, **Book → Reload** picks
it up.
