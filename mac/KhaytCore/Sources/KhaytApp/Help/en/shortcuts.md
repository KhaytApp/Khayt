# Keyboard

## Getting around

- **⌘F** — the search box.
- **⌘R** — reload the book from disk.
- **⌘,** — settings.
- **⌘?** — this help.

## Work

- **⌘N** — new job.
- **⇧⌘I** — add models to the library.
- **Space** — Quick Look the selected model, as in the Finder.
- **⌘Z** — undo the last change to the book.

## In the library

The arrow keys walk the grid, and **⇧** with them extends the selection. In an
Arabic window they walk right to left, so "next" is still next.

## In tables

Click a column heading to sort by it. The columns themselves can be shown,
hidden and reordered — right-click the heading row.
