# Backups

Khayt takes a copy of your book before anything that rewrites it, and keeps the
recent ones.

## Taking one now

**Book → Back up now**. **Book → Reveal backups** opens the folder in the
Finder, which is where to go if you want to copy one somewhere else.

## Restoring

**Book → Restore** lists what is there, newest first. Restoring replaces your
current book with that copy — so Khayt takes a backup of the current one first,
which means changing your mind is also possible.

## What is not a backup

**Export copy** is not a backup and is named so nobody reaches for it as one. It
is the copy that leaves — it has had your credentials taken out of it, and it is
for sending somewhere, not for restoring from.

## Where they are

In the app's own folder, alongside the book. They are on this Mac only: if the
disk goes, they go. A copy somewhere else is still worth having.
