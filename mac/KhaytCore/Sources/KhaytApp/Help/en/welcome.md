# Welcome to Khayt for Mac

Khayt keeps a 3D printing shop's book: the jobs you have taken, what they cost
you, what you charged, what is on the shelf and what the printers are doing.

This is the Mac app. It reads and writes the same book as Khayt for Windows and
Linux, and it computes every figure with the same shared rules — so a total here
and a total there are the same number, not two opinions.

## Where to start

If you have never opened Khayt before, the app opens on a **sample shop**: an
invented book with jobs, machines and models in it, so every screen has
something to show. Nothing you do to it touches a real book, and it is named in
the toolbar at all times.

When you have a real book, pick it from that same menu in the top-left. See
**Which book is open** for what the names mean.

## What this app is for

- Taking a job, moving it through the shop, and billing it.
- Knowing what a print actually cost — filament, machine time, electricity,
  the failures.
- Keeping the models you print and the products you sell.
- Watching the printers without standing in front of them.

## What is still only in the other app

The Mac app is newer. A few things are still done in Khayt for Windows and
Linux, and the screens here say so where it matters — the product photo and its
parts, the price tiers, the storefront. Your book is the same file either way,
so you can do one thing there and the rest here.
