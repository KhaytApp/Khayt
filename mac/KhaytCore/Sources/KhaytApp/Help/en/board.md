# The board

The board is the same jobs as the table, arranged by stage, for a shop floor
rather than a desk. It is the screen most likely to be left open all day.

## Moving work

Drag a job from one column to the next. That is the same change as using the
Job menu, and it is recorded the same way — moving a job to *Completed* asks
what the print actually took, exactly as the menu does.

## What is shown

Each card carries the job, the customer, the machine it is on and when it is
due. Urgent work sorts first, then by due date, then by what has been waiting
longest — the order somebody would work through them in.

A job running over its estimate shows the timer in a different colour, so the
one that needs looking at is the one you see.

## The board follows the search

The search box narrows the board as well as the table. A busy floor with one
customer's name typed in is the fastest way to answer "where is their job".
