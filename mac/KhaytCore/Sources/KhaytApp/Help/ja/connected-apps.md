# 接続済みアプリ

スライスしたファイルをこのMacへ直接送るスライサーと、ペアリングがうまくいかないときの対処です。

## 始める前に

- Mac版のKhayt。スライサーのペアリングはWindows版やLinux版にはありません。
- 設定 → オンライン で LANサーバーがオンになっており、**すべてのネットワークインターフェースで待ち受け（LAN）** もオンであること。オフのままではMacは自分自身にしか応答せず、スライサーは接続できません。
- Khaytプラグインを入れたOrcaSlicer 2.5.1以降が、Macと同じネットワーク上のコンピュータにあること。
- あなたが工房のオーナーかマネージャーであること。それ以外の人はスライサーのペアリングや削除ができません。

## スライサーをペアリングする

- サイドバーの **接続済みアプリ** を開き、**スライサーをペアリング** をクリックします。その後2分間、ネットワーク上のスライサーがペアリングを求めることができ、Macは入力するアドレスを表示します。
- OrcaSlicerで Khayt → Pair → On this network を開き、そのアドレスをそのまま入力します。
- Macが **「名前」を承認しますか？** と尋ね、どのアプリがどのアドレスから求めたかを示します。自分のスライサーであることを確かめてください。
- 両方の画面に6桁の数字が表示されます。同じであれば **番号が一致 — 承認** をクリックします。スライサーが「ペアリング済みのスライサー」に表示されます。

## 数字が違うときは拒否する

**拒否** をクリックします。数字が違うのは、要求があなたのスライサーから直接来ていないということで、ネットワーク上の別の何かが間に入っているおそれがあります。試しに承認してはいけません。スライサーが自分のネットワークにあることを確かめ、もう一度ペアリングしてください。「スライサーをペアリング」を1回押すと3回まで試せます。

## ペアリングしたスライサーに見えるもの、見えないもの

「スライサーから」受信箱へファイルを送り、ジョブ一覧を見ることができます。見えるのはジョブ番号・工程・機械だけで、件名や顧客は見えません。ほかに機械、工房の名前、受信箱で待っているファイルの数も見えます。帳簿・顧客・価格・設定は決して読めず、LAN PINも見えません。その鍵は帳簿ではなく、このMacのキーチェーンに保管されます。

## 「スライサーから」受信箱

スライサーが送ったものは、接続済みアプリ画面の「スライサーから」で待ちます。スライサーが計算した重さと印刷時間、送ったスライサー、そしてスライサーの要望（見積もり、ジョブ、印刷）も表示されます。ファイルごとに **ライブラリに追加**、**新規ジョブ**、**新規見積**、または **破棄** を選びます。あなたが選ぶまで、ジョブにはならず印刷も始まりません。スライサーの要望はあくまで提案です。同じファイルが2回送られても保存されるのは1回で、Khaytがそのことを知らせます。待てるファイルは100件までです。受信箱はこのMac上の帳簿の隣にあるフォルダで、同期もどこかへの送信もされません。

## スライサーを削除する

接続済みアプリ画面で、スライサーの横の **削除…** をクリックして確定します。すぐにこのMacへの送信が止まります。また使うにはペアリングし直してください。それまでに送られたファイルは受信箱に残ります。LAN PINを変えると、ペアリング済みの電話とともに、すべてのスライサーもサインアウトされます。

## ペアリングがうまくいかないとき

- **「スライサーをペアリング」が押せない:** 設定 → オンライン でLANサーバーと「すべてのネットワークインターフェースで待ち受け（LAN）」をオンにします。オンになっている場合は、オーナーかマネージャーに相談してください。あなたの役割では設定を変えられないのかもしれません。
- **スライサーがMacに届かない:** 2台を同じネットワークにつなぎます（ゲスト用Wi‑Fiは機器を分けることが多いです）。アドレスはポートまで正確に入力し、macOSのファイアウォールがオンならKhaytへの着信接続を許可します。
- **スライサーがペアリングは閉じていると言う:** ペアリングは2分間開いており、スライサーを承認すると閉じます。もう一度「スライサーをペアリング」をクリックしてください。
- **LAN PINをキーチェーンから読めなかった:** 何もペアリングされていません。設定 → オンライン でPINを設定し直し、もう一度ペアリングします。これで電話とスライサーはサインアウトされるので、それらもペアリングし直してください。
- **スライサーが受信箱がいっぱいだと言う:** 100件が待っています。いくつか取り込むか破棄してから、もう一度送ってください。
