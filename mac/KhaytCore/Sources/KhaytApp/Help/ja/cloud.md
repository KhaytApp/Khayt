# クラウド同期

Khayt Cloud は、複数のマシン間で帳簿を受け渡し、顧客が注文の状況を確認できるページを提供します。使うかどうかは任意で、クラウドなしでもアプリは完全に動作します。

## このアプリでできること

- **確認** — 帳簿とクラウドを比較して違いを表示します。何も送信しない読み取り専用の操作なので、よく分からないときも安心して実行できます。
- **送信** — 帳簿をクラウドへ送ります。
- **クラウドにだけあるものを取り込む** — クラウド上のコピーをダウンロードして、帳簿に統合します。

## 秘密情報は外に出ません

帳簿には、クラウドトークン、プリンターの API キー、ストレージの認証情報が含まれています。送信の前に、これらは取り除かれてマスクに置き換えられます。外に出るコピーにはこれらが含まれません。

## ロック

**帳簿 → Khayt Cloudをロック**を選ぶと、自動同期が止まり、メモリ上のキーも破棄されます。同期を終了する唯一の方法です。管理できない場所に Mac を置いて離れるときは、覚えておいてください。

## 2台のマシン

2台のマシンでこの帳簿を使う場合は、同期に頼る前に両方を最新版にしてください。古いビルドには新しいビルドで変更された項目が残っていることがあり、最後に書き込んだ側が優先されます。そのため、古いバージョンのまま放置されたマシンが、古い値を知らないうちに書き戻してしまうことがあります。
